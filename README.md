# Сеть с нуля

Интерактивный учебник на русском: сети, уровни L1–L7, подсети и первые шаги в администрировании Windows. Понятные примеры, анимированные обмены, объяснения терминов по нажатию и учебные задания.

[Открыть учебник](https://sillkiin.github.io/network-from-zero/)

## На iPhone

Открой ссылку в Safari. Для отдельного значка нажми «Поделиться» → «На экран “Домой”» → «Добавить». В учебнике кнопка «＋» открывает эту инструкцию и статус сохранения уроков.

При первой загрузке нужен интернет. После сообщения «Уроки сохранены на устройстве» можно заниматься без подключения. Данные сайта может удалить браузер или пользователь; при следующем открытии с интернетом уроки сохранятся снова.

Меню «Разделы» открывает весь курс. Карточки можно распределять двумя касаниями: выбрать карточку, затем коробку. Тренировка по подсетям содержит 15 вопросов за подход из банка 55 вопросов.

Прогресс хранится локально в браузере устройства. Учётных записей и синхронизации нет. Учебный терминал не выполняет команды на компьютере или телефоне и не меняет сетевые настройки.

## Размещение

Статический сайт без серверной части и сторонних библиотек. GitHub Pages: ветка `main`, корень `/`. Нужен HTTPS для сохранения уроков через service worker. Все пути относительные; сайт работает и в подпапке проекта.

Файлы для размещения: `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` и `.nojekyll`. Иллюстрации, стили и код встроены в HTML. Внешние официальные источники в словаре требуют интернета.

При обновлении service worker сначала сохраняет новую версию целиком. Если учебник уже открыт, кнопка «Обновить учебник» появляется в инструкции «＋». Обновление применяется по нажатию, чтобы не прервать упражнение.
